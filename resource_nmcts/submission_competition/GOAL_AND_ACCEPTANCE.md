# XA-202609 竞赛交付目标与验收标准

## 总目标

围绕 XA-202609“量子 + AI 双向赋能”榜题中的“AI 驱动量子编译与线路优化”，把现有 Resource-NMCTS Boolean Oracle 综合器升级为可复现、可验证、可审计的硬件感知竞赛作品：从 Boolean 函数输入出发，完成逻辑综合、拓扑约束编译、本地仿真、统计比较、数据库归档和竞赛 PDF 交付。

所有“优于”“显著提升”结论必须来自匹配实验、正确性验证和统计检验；不预造结果，不把跨抽象层代理指标表述为真实硬件优势。

## 最终交付物

1. 中文竞赛 PDF，以及可重新编译的 LaTeX/图表源文件。
2. 完整源码、运行入口、环境清单、模型权重及其校验值。
3. 原始实验结果、汇总结果、统计检验结果和 DuckDB 实验数据库。
4. Direct-ANF、SSHR、ESOP/MILP、Qiskit/SABRE 等适用基线的匹配对比。
5. 真实程序输出生成的逻辑线路、原生门线路、硬件拓扑和资源图表。
6. 一键复现、完整性校验和逐页视觉验收脚本。

## 验收门槛

- 题目一致：主线必须是 AI 赋能量子编译，而不是 XA-202605 或其他榜题。
- 电路可取：公共综合 API 能返回精确门序列和成本，图表不依赖私有分支的人工重建。
- 功能正确：逻辑线路通过符号验证；可行规模通过全输入态 Aer 验证；映射线路通过算子或测量语义验证。
- 硬件边界真实：至少覆盖显式耦合图、布局、路由、原生门集和映射后精确验证；
  “门基分解”不得冒充“硬件映射”。当前无真实校准/噪声，因此必须显式标为
  synthetic Target，并把校准/真机结果列为扩展验收，不能预写成功。
- 对比公平：相同函数、相同资源预算、明确超时规则；资源安全主分析使用预先冻结的
  20 个独立函数和 3 个完整随机种子，推断单位为 Boolean function，并报告置信区间、
  效应量和分族 Holm 校正。5 seeds × 3 transpiler seeds × 4 targets 为全量扩展层。
- AI 可归因：学习策略必须与随机、启发式和无模型版本做消融；系统收益与神经先验收益分别表述。
- 速度透明：同时报告质量、运行时间、worker 树峰值 RSS、系统内存峰值和 GPU/CPU
  使用边界；默认 70% 系统内存护栏，超限只终止当前 worker。
- 数据可追溯：每一行结果保存函数、方法、种子、配置、模型哈希、环境、后端/拓扑和验证状态。
- 视觉合格：正文图在最终版面尺度下可读，无缺字、重叠、越界、失真或无意义空白；PDF 逐页渲染检查。
- 结论克制：如某基线或某硬件指标未获胜，必须保留负结果并解释适用边界。
