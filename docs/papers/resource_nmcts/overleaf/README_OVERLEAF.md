# 双向智能 Boolean Oracle 编译中文主稿

本项目是 XA 竞赛中文技术报告的持续更新版本，不对应冻结的 `v40` 终稿。

## 编译

1. 编译器选择 **XeLaTeX**。
2. 主文件选择 `main.tex`。
3. 图片、表格和算法分别位于 `figures/`、`tables/` 和 `algorithms/`。

正文由本地规范源 `docs/papers/resource_nmcts/chinese/main.tex` 通过受控脚本同步。
