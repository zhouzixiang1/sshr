# Documentation

项目文档统一从本目录进入：

- `project/`：项目状态、总体蓝图、技术设计、架构决策、交付、合规和服务器接手；
- `contracts/`：机器可读验收矩阵及后续 schema；
- `planning/`：当前施工顺序、实验路线和阶段停止条件；
- `competition/`：官方赛题、证据、学术报告、PPT 和提交 staging；
- `papers/`：当前中英文文稿、文稿历史索引和 Overleaf 同步入口；
- `archive/`：本机历史归档的边界与恢复索引。
